\section intro_sec Introduction

This is the developer documentation of Navio Core, the Navio client software.
Navio uses peer-to-peer technology to operate with no central authority:
managing transactions and issuing money are carried out collectively by the
network.

The software is a community-driven open source project, released under the MIT
license.

See https://github.com/nav-io/navio-core and https://nav.io/ for further
information about the project.
